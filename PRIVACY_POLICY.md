# Privacy Policy for Meta Vibes Studio

**Last updated:** September 23, 2026

Meta Vibes Studio is a browser extension that helps users organize scene prompts, character and location references, and image/video generation tasks for supported Meta AI and Vibes.ai pages.

## Data handled by the extension

The extension may process content provided or selected by the user, including:

- scene and video prompts;
- character and location names and descriptions;
- reference images and local start/end frame images;
- generated image and video URLs on supported websites;
- project names, preferences, local generation counters, and technical diagnostics.

## How data is used

This information is used only to provide the extension's user-facing features: organizing projects, linking references, filling prompts, uploading user-selected media, monitoring requested generation tasks, displaying results, and saving files chosen by the user.

When the user starts an operation, the relevant prompt or media may be inserted into or uploaded through the active Meta AI or Vibes.ai page. Those services process the content under their own terms and privacy policies.

## Local storage

Project state, preferences, generation statistics, and diagnostics are stored locally in the user's browser. Files are exported only to a folder or download location selected by the user. Diagnostic records older than seven days are removed automatically.

## Remote configuration check

The extension may request a small remote configuration document to check supported extension versions and display update or informational notices. The request does not contain project prompts, reference descriptions, uploaded images, generated media, diagnostics, or account credentials. As with ordinary internet requests, the hosting provider may receive standard connection information such as an IP address and browser request metadata.

## Data we do not collect

Meta Vibes Studio does not collect or store passwords, authentication tokens, cookies, payment information, health information, precise location, or browsing history. The developer does not sell user data and does not use extension data for advertising, credit decisions, or unrelated profiling.

## Data sharing

The developer does not sell or rent user data. User-selected content is shared with Meta AI or Vibes.ai only as necessary to perform actions requested by the user. Standard request metadata may be handled by the remote configuration hosting provider as described above.

## Data security

The extension limits website access to supported Meta AI and Vibes.ai domains and uses local browser storage for extension state. Users should avoid placing secrets or sensitive personal information in prompts, filenames, descriptions, or diagnostic exports.

## User choices

Users can clear diagnostics from the extension settings, remove the extension to clear extension-managed browser storage, and delete exported project files from their own device. Users control when prompts, images, videos, and exports are sent or saved.

## Changes to this policy

This policy may be updated when the extension's behavior changes. The latest version will be published with the project repository.
