## What Meta Vibes Studio does

Meta Vibes Studio is a local-first browser extension for organizing prompts, references, generated scenes, and videos:

1. Create a project.
2. Break the story into scene prompts.
3. Define reusable characters and locations.
4. Generate reference and scene images with Meta AI.
5. Turn approved images or text prompts into videos with Vibes.ai.
6. Save the project files to your computer.

The extension does not replace Meta AI or Vibes.ai. It coordinates your prompts, references, queues, results, and project files while those websites perform generation.

## Quick start

1. Install the unpacked extension from `[chrome://extensions](https://chromewebstore.google.com/detail/meta-vibes-studio/knnkgfdihhhdiebdddeeaeeeknhnnmgf?authuser=0&hl=ar)` or `edge://extensions`.
2. Open Meta AI and launch Meta Vibes Studio from the browser toolbar.
3. Create a project and give it a clear name.
4. Add scene prompts and split them into cards.
5. Create character and location references.
6. Run the scene queue on Meta AI.
7. Open Vibes.ai and prepare video prompts.
8. Select generated scene images or upload local start/end frames.
9. Run the video queue and export the finished project.

## Data and privacy

- Project state and preferences are stored locally in the browser.
- Selected project folders remain on the user’s device.
- Diagnostics are local, can be exported manually, and entries older than seven days are removed automatically.
- The extension does not store account passwords, cookies, or website sessions.
- Meta AI and Vibes.ai remain responsible for their own accounts, generation services, and usage policies.
